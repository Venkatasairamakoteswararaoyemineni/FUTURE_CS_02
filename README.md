# Cyber Security Task 2

## Phishing Email Detection & Awareness Report

### Task Performed

In this task, I analyzed a phishing email sample and identified various phishing indicators.

### Activities Completed

* Collected a phishing email sample.
* Examined the email content.
* Analyzed email header information.
* Inspected the suspicious URL/domain.
* Identified phishing indicators such as:

  * Fake sender address
  * Generic greeting
  * Urgency-based language
  * Suspicious URL
* Classified the email as High-Risk Phishing.
* Created a phishing attack flow diagram.
* Prepared awareness and prevention guidelines.

### Conclusion

The analyzed email contained multiple phishing characteristics and was classified as a phishing email. This task helped in understanding how phishing attacks work and how users can identify and avoid them.
